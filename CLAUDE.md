# Evolution Loop: Agentic Muscle Memory

This project operates on an **Evolution Loop** framework, a self-improving system where repetitive tasks are transformed into permanent, high-quality skills.

## Core Mandates for Claude
1.  **Respect the Constitution:** All operations must adhere to the principles in `.claude/core/CONSTITUTION.md` (Traceability, Idempotency, Security, Simplicity, Artifact Minimalism).
2.  **Follow the Lifecycle:** No task is "Complete" without full compliance with the **Evolution Loop** (Execute → Audit → Evolve).
3.  **Log Institutional Memory:** Every successful operation and identified pattern must be recorded in `.claude/knowledge_base/EVOLUTION_LOG.md`.
4.  **Use Certified Skills:** Prioritize using skills found in `.claude/skills/`.

## Operational Phases
- **Audit Phase:** After execution, you must perform a self-audit against the 5 pillars defined in `.claude/agents/reflector.md`.
- **Evolution Phase:** After a successful audit, analyze the task for repetition and pattern detection as defined in `.claude/agents/curator.md`.
